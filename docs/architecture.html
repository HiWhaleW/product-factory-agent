原则

用户目标 → Factory Lead 对齐 → 用户 Gate → 子 Agent 任务与最小 Context → 工具与 RunStep → Artifact → Reviewer → 用户决定。

  • 模型负责理解与生成；确定性代码负责状态、权限、归属、幂等和审计。
  • 后端 Session 是账户与项目归属的真相源。
  • 源码环境的 PostgreSQL、Artifact、Workspace、日志与 Secret Store 统一位于 .runtime/user-preview/。
  • 每个安装实例独立；模型与搜索 API 初始为空。
  • Compose 默认只公开本机 Web，API 与数据库留在内部网络。
