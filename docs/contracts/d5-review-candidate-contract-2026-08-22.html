AI PM 提交

POST /api/v1/projects/{project_id}/definition-submissions

  1. 精确绑定当前 mrd Context Pack 和 succeeded AI PM Run。
  2. 检查 model/checkpoint Journal 和独立 Permission allow。
  3. 完整博查结果 Hash 必须匹配已确认 Tool Step。
  4. EvidenceRef 必须等于 bocha:web:sha256(url) 且属于本次结果。
  5. 精确一个 Evidence Index 和一个 MRD；Secret 样文本拒绝。
  6. 双击与重放不重复写 Artifact，也不重复收费。

Reviewer 提交与 G1

POST /api/v1/projects/{project_id}/definition-submissions/{submission_id}/review

  1. 验证 succeeded Reviewer Run、同一 Project/Context/Pack 和 model/checkpoint Journal。
  2. 持久化精确一个 EvidenceRef 非空的 Red Team Review。
  3. reject 只退回，不开 G1。
  4. pass 或 pass_with_known_issues 只开一个 G1。
  5. 项目仍为 mrd；只有用户 Gate approve 才进入 prd。
