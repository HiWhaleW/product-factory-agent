## 真实用户和项目归属

- 新增数据库真实用户、邀请码和项目所有者；邀请码只保存哈希。
- HttpOnly Session 绑定数据库用户；`/me` 返回真实用户 ID、显示名和角色。
- 项目创建自动归属当前 Session 用户，项目列表只返回该用户的项目。
- 项目、产物、任务、Run、Gate、Permission 均由后端检查归属；跨用户访问返回 404。
- A、B 两个真实数据库用户验收：A 创建项目后 B 列表仍为空；B 无法读取 A 的项目或 Graph，也不能伪造 owner ID。
