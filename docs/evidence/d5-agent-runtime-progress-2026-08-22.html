  • 4 个冻结 Agent 注册；D5 激活 Factory Lead、AI PM、Reviewer，Builder 只注册且禁止执行。
  • LangGraph 节点为 model → policy → finish，支持 maxTurns、有限 retry、timeout、结构化输出与 allow/ask/deny。
