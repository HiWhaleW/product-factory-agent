平台运行边界

  • 用户 Key 原文只进权限 0600 的分环境 Secret Store；数据库只留脱敏元数据和接口配置。
  • 用户可配置公开 HTTPS 的 OpenAI-compatible Base URL 与模型名；普通用户未配置 Key 时 Agent 拒绝执行。
  • 登录成功统一打开首页；普通用户个人信息显示角色“用户”和“用户工作空间”。
  • 项目删除进入按 Session owner 隔离的回收箱；恢复回到原阶段且重复恢复幂等；V1 不提供永久删除。
  • 生产环境必须开启认证；AG-UI/SSE 是主通道。
  • 当前都是本机 URL；公网 HTTPS、真实跨版本回滚、内测数据和 G6 尚未完成。
