本机运行
浏览器使用

Docker Compose v2 安装契约已实现

首次安装

./scripts/install/install.sh

构建并启动 Web、API 与 PostgreSQL，执行 migration，生成本机秘密并完成健康检查。

完成后打开 http://127.0.0.1:3400 创建第一个本地账户。

Docker Desktop 不是仓库组成部分。使用者自行选择兼容 Docker Engine API 与 Compose v2 的容器运行时。

安全边界

只公开 Web
API/DB 不映射宿主机端口
Builder 关闭
fail closed，无 Docker Socket
持久化
DB/Artifact/Workspace/Secret/日志
不带维护者数据
排除 .runtime/外部归档/日志/备份/秘密

备份与运维

  • ./scripts/install/health.sh
  • ./scripts/install/backup.sh
  • ./scripts/install/restore-check.sh <backup-id>
  • ./scripts/install/upgrade.sh / rollback.sh
  • ./scripts/install/uninstall.sh
证据边界

维护者电脑没有容器运行时，所以 Compose 尚未在该电脑做实机安装验收；当前源码网页可用与 Compose 安装证据必须分开陈述。
