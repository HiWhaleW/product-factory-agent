一条请求如何贯穿 7 层

关键顺序是“先校验与持久化，再执行与通知”；任何模型候选动作都不能跳过控制面。

1用户输入群聊消息、Gate 决策或权限决定，携带客户端幂等标识。
→
2控制面校验检查阶段、Gate、Task、Context、权限和预算；先写实体与 Event。
→
3Agent Run创建 Task/Run，发送版本化最小 Context Pack，启动有界循环。
→
4模型与工具DeepSeek 返回结构化候选；Tool Policy 输出 allow / ask / deny。
→
5证据与回显RunStep、ToolRun、Artifact、Reviewer、Gate 落库后，通过 Event 更新 UI。

同一概念可以有多个视图，但只能有一个能做最终裁决的来源。
