打开独立工程排期

V1 只做三件事

不用 17 个角色和大量文档制造“公司很忙”的假象。

受控项目群聊

动态入群、自介、@Agent、Context Pack、工具事件和人工闸。

累计产物 DAG

Brief、MRD、PRD、方案、后端/前端、MVP、种测、商业 BRD、发布、反馈和下一轮分支可追溯。

Harness 控制层

状态、能力、工具、预算、密钥、幂等、审计和恢复。

12 阶段与 G0-G6

Agent 可以提建议，但不可代替人决定目标、市场需求、产品范围、方案、技术栈、内测和商业发布。

共享上下文五层模型

子 Agent 获得的是版本化、最小权限 Context Pack，不是所有群聊和文档的全量复制。

L1 项目公共事实Brief、已批准决定、范围、术语、版本和风险。
L2 当前阶段输入产物、退出证据、人工闸、未解问题。
L3 子 Agent 任务包任务、必读引用、Skill/工具、Schema、预算和禁止项。
L4 私有工作区草稿、候选分析和中间失败；不共享隐藏思维链。
L5 可审计交接包产物、证据、假设、工具摘要和建议变更；审核后合并。

必须共享的情况

新 Agent 入群知道已批准事实和自己的任务边界。
上下游交接AI PM → Builder → Reviewer。
人工决定变更所有活跃 Agent 切换新 context_version。
并行合流各分支基于同一 Brief，由主 Agent 合并冲突。
线上缺陷需关联需求、代码、部署、日志和版本。
新迭代分支继承已批准主干，不改写历史。

技术架构：每一项是做什么的

技术路线已冻结，但只有骨架、部分模型/API 定义、初始 migration 和纯逻辑测试存在；未被代码与真实运行证据覆盖的部分仍是未来契约，不是已运行系统。

阅读完整技术契约
1. 用户看得到的工作台Next.js + React实现双栏页面、群聊、审批卡片和产物预览。Tailwind CSS快速实现布局、颜色和电脑/手机适配。CopilotKit把 Agent 消息、工具过程和人工审批呈现到网页。AG-UI规定后端如何实时发送消息、工具、审批和产物事件。React Flow把 Brief、PRD、代码、QA、URL 和迭代画成可点击 DAG。
→
2. 后端与 Agent 运行DeepSeek Adapter给 4 个 Agent 提供理解、生成和工具调用；渠道、模型名和 Base URL 最晚 D5 前冒烟。FastAPI提供项目、群聊、产物、审批和反馈等后端 API。Pydantic校验 Agent、工具和 API 数据，不盲信模型文本。LangGraph管理有界 Agent Loop、工具回调、等人审批和恢复；它不等于 RAG。确定性状态机 / Gate Policy硬性决定阶段、审批、权限、预算和幂等，不依赖 Prompt 自律。
→
3. 数据、文件与代码执行PostgreSQL保存项目、事件、Context、Task、Gate 和产物版本。SQLAlchemy + Alembic安全读写数据库，并记录表结构的升级/回滚。Local Artifact Store保存 Markdown、代码、测试报告等实际文件。Codex CLI Adapter让 Builder 只在已批准工作区写代码、跑测试和修复。pytest / Vitest / Playwright分别检查后端、前端逻辑和真实浏览器流程。
RAG：V1 不做Context Pack 按项目、阶段、产物和版本精确取回；不引入 embedding 和向量库。
DeepSeek：当前供应商V1 仅接 DeepSeek；具体模型、Base URL、工具调用和 Schema 能力待真实冒烟。
Agent Loop：有，但有上限模型→工具→结果可续跑，但受轮次、重试、超时、预算、人工闸和 Reviewer 限制。
LangGraph：只管 Run负责循环、interrupt 和恢复；业务阶段与权限仍由确定性代码决定。
