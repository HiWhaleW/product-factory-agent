造物工场

一个本地优先的 AI Native 产品交付 Agent。用户说清目标，Agent 围绕 Context、工具、产物、Reviewer 与人工 Gate 推进工作。

启动后通过浏览器访问 http://127.0.0.1:3400
Web、API、PostgreSQL 与用户数据运行在使用者自己的电脑。

本地运行

git clone https://github.com/HiWhaleW/product-factory-agent.git
cd product-factory-agent
./scripts/install/install.sh

完成后打开 http://127.0.0.1:3400。Docker Desktop 不属于本项目；使用者自行选择兼容 Docker Engine 与 Compose v2 的运行时。

证据边界
源码测试与构建通过；维护者电脑尚未做 Compose 实机安装验收。模型与搜索 API 默认为空，未配置时不伪造 Agent 结果。
